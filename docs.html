Clover CSS · Version 2.0

Build with a visual language.

Clover is a customizable CSS framework for expressive, durable interfaces. Start with a considered foundation, shape the design system with tokens, then compose pages with responsive primitives and purposeful components.

Design systemCSS nativeNo runtime

Installation

Install the package or use the stylesheet directly. Clover does not require a JavaScript runtime or a build pipeline.

npm install @spideythedev/clover-css
<link rel="stylesheet" href="clover.css">

Quick start

Compose semantic HTML with Clover classes. Keep behavior in your application and presentation in the stylesheet.

<main class="clover-container clover-stack">
  <section class="clover-card" data-variant="raised">
    <span class="clover-badge" data-variant="success">Ready</span>
    <h2>A more considered interface.</h2>
    <p>A clean foundation for your next idea.</p>
    <button class="clover-button">Explore Clover</button>
  </section>
</main>

Design tokens

Override a few tokens to establish a distinct visual identity across the entire interface.

:root {
  --clover-primary: #3159c9;
  --clover-primary-hover: #2447aa;
  --clover-radius-md: 1rem;
  --clover-radius-lg: 1.5rem;
  --clover-font-sans: "Manrope", system-ui, sans-serif;
  --clover-content-width: 82rem;
}

Theme control

Automatic mode follows the user's color preference. Explicit theme attributes override it at any level.

<html data-clover-theme="dark">

Use light or dark. Remove the attribute for automatic mode.

<div data-clover-radius="soft" data-clover-density="comfortable">...</div>

Radius presets are sharp and soft. Density presets are compact and comfortable.

Layout primitives

Available patterns: container, stack, cluster, grid, grid-auto, split, center and flow.

<div class="clover-container">
  <div class="clover-grid-auto" style="--clover-grid-min: 18rem">
    <article class="clover-card">One</article>
    <article class="clover-card">Two</article>
  </div>
</div>

Components

Components include cards, buttons, badges, fields, inputs, selects, textareas, checkboxes, radios, switches, tabs, accordions, breadcrumbs, tooltips, alerts, avatars, progress, skeletons, tables, navigation, panels, stats, pagination, empty states and dividers.

Visual effects

The original visual experiments remain available as a separate stylesheet, keeping the core focused and easy to adopt.

<link rel="stylesheet" href="clover.css">
<link rel="stylesheet" href="clover-effects.css">

The effects sheet contains glass, clay, neubrutal, cyber, magnetic, liquid, typewriter, kaleidoscope, morphing, parallax and 3D treatments.

Accessibility

Use native HTML semantics first. Clover provides visible focus states, reduced-motion handling, responsive patterns and system-aware color schemes. Add accessible names, validation and keyboard interactions in your application.

Browser support

The core targets current evergreen browsers and uses cascade layers, custom properties, grid and modern color functions. Test your target browser matrix before shipping critical interfaces.
