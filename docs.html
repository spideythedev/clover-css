Clover CSS · Version 3.0

One family. A thousand expressions.

ChloroPhilix is a unified visual language for the web. A violet-indigo color family, distinctive geometry and a consistent component rhythm create interfaces that feel related without feeling repetitive.

ChloroPhilixCSS nativeLight + darkToken driven

Installation

Install the package or load the stylesheet directly. The core design system does not require a JavaScript runtime.

npm install @spideythedev/clover-css
<link rel="stylesheet" href="clover.css">

Quick start

Compose semantic HTML with layout primitives and component classes.

<main class="clover-container clover-stack">
  <section class="clover-card" data-variant="raised">
    <span class="clover-badge" data-variant="primary">ChloroPhilix</span>
    <h2>One visual language.</h2>
    <p>Every detail in sync.</p>
    <button class="clover-button">Get started</button>
  </section>
</main>

One color family

The system is built around a violet-indigo tonal range. Neutral surfaces and ink provide structure; all expressive accents stay inside the same family.

Available tokens run from --clover-violet-50 through --clover-violet-950.

Design tokens

Override the system at the root or scope changes to a specific region.

:root {
  --clover-primary: #6252dc;
  --clover-primary-hover: #5142bd;
  --clover-accent: #ebe8ff;
  --clover-radius-md: 1rem;
  --clover-radius-lg: 1.4rem;
  --clover-content-width: 84rem;
}

Theme control

Set an explicit theme on the root element. Remove the attribute to follow the operating system preference.

<html data-clover-theme="dark">

Shape and density

<div data-clover-radius="soft" data-clover-density="comfortable">
  ...
</div>

Radius presets: sharp, default and soft. Density presets: compact, default and comfortable.

Layout primitives

Compose responsive layouts without introducing a separate utility dependency.

<div class="clover-container">
  <div class="clover-grid-auto" style="--clover-grid-min: 18rem">
    <article class="clover-card">One</article>
    <article class="clover-card">Two</article>
  </div>
</div>

Container, stack, cluster, grid, grid-auto, split, center and flow.

50 hyper-classified components

Fifty distinct component primitives, organized into five practical systems. Each class is presentation-only: use native HTML for behavior, keyboard interaction, validation and accessible naming.

Accessibility

Use semantic HTML and native controls. Clover includes visible focus styles, reduced-motion handling and responsive layout primitives. Application-specific keyboard behavior, labels, validation and ARIA remain with the consuming application.
